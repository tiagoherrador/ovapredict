# Authorized congress figures

All graphics in `figures/congress-2026/` are authorized, English-language presentation figures adapted from the approved congress-poster material. They present aggregate research communication only; no patient identifiers, raw images, or case-level metadata are included.

| File | Description |
| --- | --- |
| `00_model_workflow_en_native.png` | High-level workflow from multiplex image to morphospatial profile. |
| `01_morphospatial_map_of_morphotypes_en_native.png` | Visual map of the identified morphotypes. |
| `02_representative_patches_en_native.png` | Representative de-identified tissue patches by morphotype. |
| `03_patient_morphospatial_composition_en_native.png` | Aggregate composition display across diagnostic groups; individual bars carry no identifiers. |
| `04_diagnostic_gradient_en_native.png` | Preliminary association of morphotypes with diagnostic category. |
| `05_biomarker_intensity_signature_en_native.png` | Exploratory biomarker-intensity signature by morphotype. |

Figures communicate preliminary results and must be interpreted alongside the limitations in [Current status and roadmap](status-and-roadmap.md).
